# FDAM：美联储双目标政策关注度模型

## 数据采集清单、历史参数估计与文本动态校准规范

**版本：** 1.0  
**研究对象：** 美国联邦储备委员会及联邦公开市场委员会（FOMC）  
**研究目标：** 判断当前美联储的政策压力更偏向通胀还是就业，并通过历史数据估计模型参数，再利用主席的议息会议后新闻发布会实录进行动态校准。

---

# 一、研究目标与基本原则

## 1.1 核心研究问题

模型需要回答五个问题：

1. 当前通胀距离长期目标有多远？
2. 当前就业市场距离充分就业状态有多远？
3. 历史上，美联储的利率决策对通胀与就业变化分别有多敏感？
4. 主席最新新闻发布会是否显示政策关注重点发生变化？
5. 将文本信息加入模型后，能否改善对未来 FOMC 政策决策的样本外预测？

最终输出：

- 通胀压力指数。
- 就业压力指数。
- 历史政策反应权重。
- 主席文本关注度指数。
- 动态通胀与就业相对权重。
- 加息、降息或维持利率的预测概率。
- 模型置信度和参数不确定性。

## 1.2 必须遵守的研究原则

### 原则 A：区分经济状态与政策关注度

通胀偏离目标的程度，不等于美联储对通胀的关注度。

失业率上升的幅度，也不等于美联储对就业的关注度。

模型必须分别计算经济压力和政策反应。

### 原则 B：不将 4% 失业率视为固定官方目标

通胀长期目标采用 2%。

就业参考值采用动态均衡失业率估计，并以固定 4% 参考值作为基准模型的对照组。

不得将 4% 失业率描述为美联储正式承诺的就业目标。

### 原则 C：区分历史政策行为和当前政策沟通

历史数据模型负责估计过去的政策反应。

新闻发布会模型负责识别当前政策沟通中的风险重点。

文本信号只能在经过历史验证后影响动态权重。

### 原则 D：禁止未来信息泄漏

任何历史预测只能使用预测时点已经公开的数据。

必须区分：

- 数据所属日期。
- 数据发布日期。
- 数据实际采集日期。
- 历史数据版本日期。

对于历史决策回测，优先使用当时可获得的数据版本。

### 原则 E：保留模型不确定性

不得只输出一个看似精确的关注度百分比。

必须同时报告参数估计区间、样本外预测表现、数据完整性和模型局限。

# 三、D1：通胀与价格指数数据

## 3.1 原始数据清单

| 字段名 | FRED 系列代码 | 频率 | 用途 | 优先级 |
|---|---|---|---|---|
| pce_price_index | PCEPI | 月度 | 总体 PCE 价格指数 | P0 |
| core_pce_price_index | PCEPILFE | 月度 | 核心 PCE 价格指数 | P0 |
| cpi | CPIAUCSL | 月度 | 总体 CPI | P1 |
| core_cpi | CPILFESL | 月度 | 核心 CPI | P1 |
| gdp_deflator | GDPDEF | 季度 | GDP 价格指数 | P2 |
| breakeven_5y | T5YIE | 日度 | 5 年期市场隐含通胀补偿 | P1 |
| breakeven_10y | T10YIE | 日度 | 10 年期市场隐含通胀补偿 | P1 |
| michigan_inflation_expectations | MICH | 月度 | 消费者通胀预期辅助指标 | P1 |

采集时必须保存每个系列的官方名称、单位、季节调整方式、来源机构、首次可用日期和最新可用日期。

如果某个系列在指定历史区间不存在，不得自动填充虚构数据，应记录缺失原因并调整该模型的可用样本。

## 3.2 衍生变量

必须生成：

| 字段名 | 定义 | 用途 |
|---|---|---|
| pce_yoy | 总体 PCE 同比变化率 | 主要通胀指标 |
| core_pce_yoy | 核心 PCE 同比变化率 | 基础通胀趋势 |
| pce_3m_annualized | 总体 PCE 三个月年化变化率 | 短期通胀趋势 |
| core_pce_3m_annualized | 核心 PCE 三个月年化变化率 | 核心通胀短期趋势 |
| pce_gap | pce_yoy - 2 | 通胀目标偏离 |
| core_pce_gap | core_pce_yoy - 2 | 核心通胀目标偏离 |
| inflation_acceleration | 当前通胀与过去三个月趋势的差值 | 通胀加速识别 |
| inflation_expectations_gap | 通胀预期与 2% 的差值 | 预期脱锚风险 |

同比通胀：

\[
\pi_t=100\left(\frac{P_t}{P_{t-12}}-1\right)
\]

三个月年化通胀：

\[
\pi_{t,3m}
=100\left[\left(\frac{P_t}{P_{t-3}}\right)^4-1\right]
\]

其中，\(P_t\) 为相应价格指数。

三个月年化指标必须明确标记为短期趋势估计，不能直接替代美联储的长期通胀目标。

## 3.3 数据使用规则

1. 总体 PCE 是主要目标指标。
2. 核心 PCE 用于识别潜在通胀压力。
3. CPI 只作为补充，不得直接替代 PCE。
4. 通胀预期指标不能与实际通胀率直接相加。
5. 对通胀低于 2% 的情况，必须保留偏离方向。
6. 不得简单使用绝对值后丢弃方向，因为通胀过高与通胀过低可能对应不同政策压力。

|---|---|---|---|---|
| unemployment_rate | UNRATE | 月度 | 核心就业指标 | P0 |
| nonfarm_payrolls | PAYEMS | 月度 | 非农就业人数 | P0 |
| labor_force_participation | CIVPART | 月度 | 劳动参与率 | P1 |
| employment_population_ratio | EMRATIO | 月度 | 就业人口比 | P1 |
| initial_claims | ICSA | 周度 | 初次失业救济申请 | P1 |
| continued_claims | CCSA | 周度 | 持续失业救济申请 | P1 |
| job_openings_rate | JTS1000JOL | 月度 | 职位空缺率 | P1 |
| average_hourly_earnings | CES0500000003 | 月度 | 平均时薪 | P1 |

职位空缺率系列必须核对当前 FRED 元数据，确认其行业覆盖范围、单位及历史起始日期。

如果行业覆盖范围发生变化，应在数据字典中记录。

## 4.2 必须生成的衍生变量

| 字段名 | 计算方式 | 用途 |
|---|---|---|
| unemployment_gap_fixed | 失业率 - 4% | 固定参考值基准模型 |
| unemployment_gap_dynamic | 失业率 - 动态均衡参考值 | 主模型 |
| unemployment_change_3m | 当前失业率 - 三个月前失业率 | 识别就业恶化速度 |
| unemployment_change_6m | 当前失业率 - 六个月前失业率 | 识别中期趋势 |
| payroll_change_1m | 非农就业人数月度变化 | 当月就业增长 |
| payroll_change_3m_avg | 最近三个月非农就业月均增量 | 平滑就业噪声 |
| payroll_growth_12m | 非农就业人数同比增速 | 中期就业趋势 |
| claims_4w_avg | 初次失业救济申请四周平均值 | 识别裁员趋势 |
| wage_growth_yoy | 平均时薪同比增速 | 工资压力辅助指标 |
| vacancies_change | 职位空缺变化 | 劳动力需求变化 |

就业压力必须同时考虑水平和变化速度。

例如：

- 失业率水平较高但稳定。
- 失业率仍然不高但快速上升。

这两种状态不能被模型视为完全相同。

## 4.3 动态均衡失业率

建议设置两个版本：

**基准版本：**

\[
G_{u,t}^{fixed}=u_t-4\%
\]

**动态版本：**

\[
G_{u,t}^{dynamic}=u_t-u_t^*
\]

其中，\(u_t^*\) 是自然失业率或长期均衡失业率的估计值。

可使用 CBO 等机构发布的自然失业率估计作为外部参考。

必须保存参考值的发布日期和历史版本。

不能使用未来公布的均衡失业率估计，回填为历史会议当时已知的值。

## 5.2 衍生变量

至少生成：

- 实际 GDP 同比增长率。
- 实际 GDP 季度年化增长率。
- 实际消费同比增长率。

它们不直接代表美联储的双目标之一。

不能因为 GDP 增长放缓，就直接提高就业关注度；必须结合就业数据和政策反应进行判断。

# 六、D4：货币政策与利率数据

## 6.1 原始数据

| 字段名 | 来源 | 频率 | 用途 | 优先级 |
|---|---|---|---|---|
| effective_fed_funds_rate | EFFR | 日度 | 实际有效联邦基金利率 | P0 |
| target_rate_lower | FOMC 声明及实施说明 | 会议级 | 目标区间下限 | P0 |
| target_rate_upper | FOMC 声明及实施说明 | 会议级 | 目标区间上限 | P0 |
| policy_rate_midpoint | 根据目标区间计算 | 会议级 | 主要政策结果变量 | P0 |
| policy_rate_change | 相邻会议中点之差 | 会议级 | 加息、降息或维持 | P0 |
| reserve_balance | H.4.1 / FRED 对应系列 | 周度 | 银行准备金环境辅助指标 | P2 |
| fed_assets | H.4.1 / FRED 对应系列 | 周度 | 美联储资产负债表辅助指标 | P2 |

对于利率目标区间中点：

\[
i_t=\frac{i_t^{lower}+i_t^{upper}}{2}
\]

相邻会议的政策利率变化：

\[
\Delta i_t=i_t-i_{t-1}
\]

分类标签：

- `hike`：目标区间中点上升。
- `cut`：目标区间中点下降。
- `hold`：目标区间中点不变。

政策利率必须以 FOMC 决策为准。

EFFR 仅作为实际市场利率的补充指标。

## 6.2 必须采集的政策事件

每次会议记录：

- 会议开始日期。
- 会议结束日期。
- 政策声明发布时间。
- 新闻发布会时间。
- 目标利率区间。
- 区间变化幅度。
- 是否召开新闻发布会。
- 是否发布 SEP。
- 是否存在重要政策框架变化。
- 是否存在紧急会议或会议间政策调整。

必须单独处理会议间紧急降息、特殊流动性措施和其他非常规政策行动。

不允许仅因为动态模型回测效果更好，就忽略它可能存在的前视偏差。

# 九、D7：主席新闻发布会文本数据库

## 9.1 采集范围

第一阶段建议从 2011 年以来有可用新闻发布会实录的会议开始。

之后再根据需要扩展到更早时期。

采集流程：

1. 从美联储官方会议资料页面发现会议。
2. 获取新闻发布会官方链接。
3. 下载 HTML 或 PDF。
4. 保存未经修改的原始文件。
5. 解析主席开场陈述。
6. 解析记者提问与主席回答。
7. 为每个段落记录发言人。
8. 保存时间戳或段落序号。
9. 对解析结果进行质量检查。
10. 生成文本分析特征。

## 9.2 文本数据库字段

建议建立 `press_conference_segments` 表。

| 字段 | 类型 | 说明 |
|---|---|---|
| meeting_id | string | 关联会议 |
| segment_id | string | 段落唯一编号 |
| speaker_role | enum | chair/reporter/other/unknown |
| section_type | enum | opening_statement/qa/other |
| paragraph_index | integer | 段落序号 |
| raw_text | text | 原始文本 |
| normalized_text | text | 规范化文本 |
| source_url | string | 官方来源 |
| parser_version | string | 解析器版本 |
| content_hash | string | 原始内容哈希 |
| parse_status | enum | success/partial/failed |

不得将记者的提问直接计入主席主动强调某个问题的频率。

对于无法确认发言人的段落，应标记为 `unknown`，不参与核心关注度计算。

## 9.3 文本特征数据库

建立 `speech_features` 表，至少包括：

- `inflation_salience`
- `employment_salience`
- `inflation_risk`
- `employment_risk`
- `inflation_trend`
- `employment_trend`
- `policy_urgency`
- `policy_uncertainty`
- `policy_guidance`
- `evidence_coverage`
- `classifier_confidence`
- `annotation_version`

每个特征都必须保留对应的证据段落。

模型必须能够追溯：为什么某次会议的通胀关注度上升，究竟是哪几段主席发言产生了影响。

# 十、统一数据结构和历史版本管理

## 10.1 原始数据表

建立 `macro_observations` 表。

字段：

- `series_id`
- `series_name`
- `observation_date`
- `release_date`
- `retrieved_at`
- `vintage_date`
- `value`
- `unit`
- `frequency`
- `seasonal_adjustment`
- `source`
- `source_url`
- `revision_status`

建议使用 Parquet 存储批量数据，使用 SQLite 或 DuckDB 维护索引、事件表和元数据。

原始数据必须不可变。

修订后的数据保存为新版本，不得直接覆盖历史文件。

## 10.2 实时可用数据集

建立 `real_time_macro` 数据集。

每条记录表示：

“在某次 FOMC 会议召开之前，市场参与者已经能够获得哪些经济数据？”

该数据集应根据实际发布日期构造。

如果暂时无法恢复某项数据的历史版本，必须标记为 `latest_vintage_proxy`，并将相关回测结果列为近似结果，而不是严格实时回测。

## 10.3 数据质量规则

每次下载后自动检查：

1. 日期是否重复。
2. 是否出现不合理的缺失区间。
3. 单位是否发生变化。
4. 频率是否符合预期。
5. 价格指数是否出现异常跳变。
6. 会议日期是否与官方资料一致。
7. 文件是否损坏。
8. 原始文件哈希是否发生变化。
9. 数据发布日期是否晚于对应预测时点。
10. 是否存在使用未来修订值的风险。

所有质量检查必须生成机器可读报告。

# 十一、历史参数评估的总体方案

历史参数评估分为五个阶段：

1. 描述性分析。
2. 基准模型估计。
3. 滚动参数估计。
4. 历史事件与制度变化分析。
5. 样本外预测检验。

第一版模型优先采用可解释的统计模型。

暂时不使用复杂的深度学习模型预测利率决策。

---

# 十二、第一阶段：描述性分析

在正式估计参数前，先完成以下分析。

## 12.1 统计特征

计算：

- 总体 PCE 通胀率均值、标准差和分位数。
- 核心 PCE 通胀率均值、标准差和分位数。
- 失业率均值、标准差和分位数。
- 失业率变化速度的分布。
- 非农就业增量的分布。
- 会议利率变化的分布。
- 加息、降息和维持不变的次数。

## 12.2 周期与制度分析

分别观察：

- 经济扩张时期。
- 经济衰退时期。
- 高通胀时期。
- 低通胀时期。
- 有效利率下限时期。
- 疫情及后疫情时期。

这些分类主要用于解释模型表现，不应在观察回测结果后随意修改分类规则。

## 12.3 相关性分析

计算通胀、失业率、经济增长与利率变化之间的相关关系。

相关性只能作为探索工具，不能直接解释为因果关系。

---

# 十三、第二阶段：建立历史基准模型

建议估计三组模型。

## 13.1 模型 A：简单双目标偏离模型

定义：

\[
G_{\pi,t}=\pi_t-2
\]

\[
G_{u,t}=u_t-u_t^*
\]

建立会议级模型：

\[
\Delta i_t=
\beta_0+
\beta_{\pi}G_{\pi,t}+
\beta_uG_{u,t}+
\varepsilon_t
\]

其中：

- \(\Delta i_t\) 为目标利率区间中点的变化。
- \(\beta_{\pi}\) 为通胀偏离的关联系数。
- \(\beta_u\) 为失业率偏离的关联系数。

该模型是最简单的基准模型。

需要预先说明：如果通胀上升伴随失业率下降，或者失业率上升伴随通胀下降，二者可能高度相关，导致系数估计不稳定。

因此，不能只报告系数大小，还应报告置信区间、标准误和多重共线性诊断。

## 13.2 模型 B：加入趋势与经济周期变量

扩展为：

\[
\Delta i_t=
\beta_0+
\beta_{\pi}G_{\pi,t}+
\beta_uG_{u,t}+
\beta_{\pi s}S_{\pi,t}+
\beta_{us}S_{u,t}+
\beta_gG_{g,t}+
\varepsilon_t
\]

其中：

- \(S_{\pi,t}\) 为通胀趋势或加速度变量。
- \(S_{u,t}\) 为失业率变化速度。
- \(G_{g,t}\) 为产出缺口或经济增长指标。

该模型用于判断美联储是否不仅对经济指标的当前水平作出反应，还对变化趋势作出反应。

## 13.3 模型 C：利率平滑模型

引入利率惯性：

\[
i_t=
\rho i_{t-1}+
(1-\rho)i_t^*+
\varepsilon_t
\]

其中：

\[
i_t^*=
r_t^*+\pi_t+
\phi_{\pi}G_{\pi,t}+
\phi_uG_{u,t}
\]

这里的 \(r_t^*\) 为中性实际利率估计。

模型 C 用于识别政策调整的惯性。

必须注意：

- 利率平滑模型不能自动解决内生性问题。
- 中性利率属于估计变量。
- 参数应按时期重新估计并进行稳定性检验。
- 该模型仅描述历史政策行为，不代表美联储实际使用的内部公式。

---

# 十四、第三阶段：将系数转换为可比较的关注权重

不能直接比较未经标准化的通胀和失业率回归系数。

原因是二者的单位不同。

建议采用以下步骤。

## 14.1 标准化经济变量

使用训练窗口内的均值与标准差：

\[
Z_{\pi,t}=
\frac{\pi_t-\mu_{\pi}}{\sigma_{\pi}}
\]

\[
Z_{u,t}=
\frac{u_t-u_t^*-\mu_u}{\sigma_u}
\]

标准化参数只能使用训练窗口估计，并在验证集和测试集上保持固定。

如果采用滚动标准差，应明确滚动窗口长度，且不能使用未来数据。

## 14.2 估计标准化系数

建立：

\[
\Delta i_t=
\beta_0+
\beta_{\pi}Z_{\pi,t}+
\beta_uZ_{u,t}+
\varepsilon_t
\]

## 14.3 计算历史相对敏感度

可以定义：

\[
W_{\pi}^{hist}
=
\frac{|\beta_{\pi}|}
{|\beta_{\pi}|+|\beta_u|}
\]

\[
W_u^{hist}=1-W_{\pi}^{hist}
\]

但该权重只是一种描述性指标。

它不是美联储官方公布的目标权重，也不一定能直接代表官员的真实注意力。

必须同时报告：

- 原始回归系数。
- 标准化回归系数。
- 置信区间。
- 参数稳定性。
- 样本外表现。

如果两个系数的估计不确定性很大，或者其中一个系数接近零，则不应把归一化结果解释为可靠的关注度比例。

---

# 十五、第四阶段：滚动估计与参数稳定性

美联储的政策框架会变化，因此不能假设 1990 年至今只有一个稳定的政策反应函数。

建议建立以下模型版本。

| 模型 | 样本 | 用途 |
|---|---|---|
| Long-run | 1990 年至最新可用日期 | 长期基准 |
| Pre-GFC | 1990—2007 年 | 金融危机前参考 |
| Low-rate | 2009—2019 年 | 低利率环境 |
| Pandemic | 2020 年至最新可用日期 | 疫情及后疫情时期 |
| Rolling-10Y | 最近 10 年滚动窗口 | 近期政策敏感度 |
| Rolling-15Y | 最近 15 年滚动窗口 | 中期政策敏感度 |

这些分段是研究设计，不代表每个时期内部的政策反应一定稳定。

建议进一步使用：

- 滚动回归。
- 参数置信区间。
- 结构变化检验。
- 必要时的状态空间模型。

如果样本数量不足，不应为了得到更多参数而强行增加模型复杂度。

对于会议级数据，观察数量远少于月度宏观数据。应避免把月度数据简单重复到每次会议，从而制造虚假的独立样本。

---

# 十六、第五阶段：构建真正的样本外回测

这是整个参数评估中最重要的环节。

不能只用历史拟合优度判断模型好坏。

## 16.1 预测任务

建立三个预测任务。

### 任务 A：预测下一次会议的政策行动

分类：

- 加息。
- 降息。
- 维持不变。

### 任务 B：预测下一次会议的利率变化

目标：

\[
y_t=\Delta i_t
\]

以基点为单位。

### 任务 C：预测未来政策关注点变化

目标是下一次新闻发布会的文本关注度变化，或者下一次会议政策行动所体现的相对政策压力。

该任务需要单独评估，不能与利率变化预测混为一谈。

## 16.2 时间序列验证

采用扩展窗口或滚动窗口。

示例：

1. 使用 1990—2009 年的数据训练。
2. 预测 2010 年下一次会议。
3. 将实际结果加入训练集。
4. 重新估计模型。
5. 预测下一次会议。
6. 持续重复至最新可用日期。

样本切分必须按照时间顺序。

禁止随机打乱所有会议后进行训练集和测试集划分。

如果采用滚动窗口，应预先确定窗口长度，并在训练阶段选择参数，避免利用最终测试集反复调整模型。

## 16.3 评价指标

| 预测任务 | 评价指标 |
|---|---|
| 加息、降息、维持分类 | Macro-F1、Balanced Accuracy |
| 会议行动概率预测 | 多分类 Log Loss、Brier Score |
| 利率变化幅度 | MAE、RMSE |
| 预测概率可靠性 | Calibration Curve、Brier Score |
| 模型增量价值 | 相对于基准模型的样本外损失改善 |

对于分类任务，必须同时报告混淆矩阵。

由于维持利率可能远比加息或降息更常见，不能只使用准确率作为评价指标。

对于概率预测，必须评估概率校准。

如果模型预测某类决策的概率长期偏高，即使偶尔预测正确，也不代表它是可靠的概率模型。

## 16.4 与基准模型比较

至少设置以下基准：

- 永远预测维持利率。
- 使用上一次会议政策行动的简单模型。
- 只使用通胀的模型。
- 只使用就业的模型。
- 同时使用通胀与就业的模型。
- 加入经济增长变量的模型。
- 加入主席文本特征的完整模型。

完整模型只有在时间序列样本外测试中表现出稳定的增量价值，才可以被认定为优于简单模型。

# 十七、主席文本分析的参数校准方案

## 17.1 文本模型输入

文本分析必须区分：

- 主席开场陈述。
- 记者提问。
- 主席回答。
- 主席明确表达的风险判断。
- 主席对未来政策的指引。
- 对既有政策决定的解释。

文本模型不得只根据关键词数量决定关注度。

## 17.2 人工标注

建议从不同经济环境中分层抽取新闻发布会段落，建立人工标注集。

每段至少标注：

- 通胀相关程度。
- 就业相关程度。
- 风险严重程度。
- 趋势方向。
- 政策紧迫程度。
- 是否明确关联政策决策。
- 是否属于记者提问。
- 是否属于主席主动陈述。

先进行人工标注，再评估分类器。

至少报告：

- 各标签 Precision。
- 各标签 Recall。
- 各标签 F1。
- 标注者一致性。
- 证据段落的准确提取率。

如果分类器无法可靠区分主席观点与记者提问，文本模型不得进入动态参数更新阶段。

## 17.3 文本信号与历史参数融合

设历史模型得到的通胀权重为：

\[
W_{\pi,t}^{hist}
\]

文本模型得到的通胀关注度为：

\[
W_{\pi,t}^{text}
\]

可以先使用对数几率进行融合：

\[
L_t^{hist}
=
\log\left(
\frac{W_{\pi,t}^{hist}}
{1-W_{\pi,t}^{hist}}
\right)
\]

\[
L_t^{text}
=
\log\left(
\frac{W_{\pi,t}^{text}}
{1-W_{\pi,t}^{text}}
\right)
\]

然后：

\[
L_t^{new}
=
L_t^{hist}
+\kappa_t
\left(L_t^{text}-L_t^{hist}\right)
\]

最终：

\[
W_{\pi,t}^{new}
=
\frac{1}{1+\exp(-L_t^{new})}
\]

就业权重：

\[
W_{u,t}^{new}=1-W_{\pi,t}^{new}
\]

其中，\(\kappa_t\) 为文本更新系数。

该方法只有在历史权重与文本权重具有可比较的定义和尺度时才适用。

如果两种权重衡量的并非同一概念，不能直接融合，必须先建立明确的映射关系。

## 17.4 文本更新系数的评估

建议在训练阶段测试一组候选值，例如：

\[
\kappa\in\{0,0.1,0.2,0.3,0.5,0.75,1.0\}
\]

这些数值仅为待评估的候选参数，不代表已经得到验证的最优值。

采用滚动样本外回测，比较不同 \(\kappa\) 下：

- 下一次会议政策行动的 Log Loss。
- Brier Score。
- 利率变化预测 MAE。
- 概率校准情况。
- 不同经济时期的稳定性。

如果最佳结果始终出现在 \(\kappa=0\)，说明文本信号在当前定义下没有提供足够的增量预测价值。

这种情况下应保留文本报告，但暂时不让文本调整历史参数。

# 十八、文本模型与历史回归的最终验收标准

模型必须通过以下测试，才能允许文本信号动态修改关注度参数。

## 验收 A：文本分类质量

- 能够正确区分主席与记者。
- 能够识别通胀和就业相关语境。
- 能够区分风险恶化、改善和稳定。
- 能够保留原始证据段落。
- 对模糊语句可以输出不确定，而不是强行判断。

## 验收 B：历史参数稳定性

- 不同训练窗口下的系数变化可解释。
- 标准误和置信区间已报告。
- 不存在明显的数据泄漏。
- 参数变化不会仅由单次极端会议决定。

## 验收 C：样本外预测增量

加入文本后，应与不加入文本的模型比较。

如果文本模型未能稳定改善样本外预测，就不允许自动调整历史参数。

## 验收 D：可追溯性

每次动态权重变化必须记录：

- 变化前的参数。
- 新增的宏观数据。
- 新增的文本特征。
- 文本证据段落。
- 使用的模型版本。
- 更新系数。
- 更新后的参数。
- 样本外验证结果。

## 验收 E：降级机制

出现以下情况时，系统必须停止自动调整：

- 最新新闻发布会实录下载失败。
- 文本解析不完整。
- 关键数据缺失。
- 分类器置信度过低。
- 参数估计不稳定。
- 样本外预测质量显著恶化。

此时保留上一版有效参数，并明确报告数据或模型异常。

# 二十一、最终报告格式

每次运行生成一份结构化报告，至少包括：

## A. 当前经济状态

- 最新总体 PCE 通胀。
- 最新核心 PCE 通胀。
- 最新失业率。
- 失业率变化速度。
- 非农就业趋势。
- 数据发布日期与可用性。

## B. 历史参数

- 通胀回归系数。
- 就业回归系数。
- 标准化后的相对敏感度。
- 参数置信区间。
- 长期与近期估计的差异。

## C. 主席文本分析

- 最新新闻发布会日期。
- 通胀关注度。
- 就业关注度。
- 风险趋势。
- 关键证据段落。
- 分类器质量与置信度。

## D. 融合结果

- 历史通胀权重。
- 历史就业权重。
- 文本通胀权重。
- 文本就业权重。
- 动态通胀权重。
- 动态就业权重。
- 本次参数变化的具体原因。

## E. 预测表现

- 纯宏观模型的样本外表现。
- 加入文本后的样本外表现。
- 概率校准结果。
- 不同历史时期的表现。
- 模型当前是否允许自动调整参数。

## F. 结论

结论必须区分：

1. 当前经济数据体现的压力。
2. 历史政策反应体现的敏感度。
3. 主席当前讲话体现的政策沟通重点。
4. 模型对未来决策的预测。

不能将上述四者混为一个没有解释的百分比。

# 二十二、项目完成的最终定义

当且仅当以下条件全部满足，才认为 FDAM 第一版完成：

1. 核心宏观数据能够自动更新。
2. 历史 FOMC 会议事件完整可追溯。
3. 历史参数可以重复估计。
4. 参数估计有置信区间和稳定性分析。
5. 历史回测不存在已知的未来信息泄漏。
6. 主席新闻发布会实录可以自动采集和解析。
7. 文本关注度可以追溯到具体证据段落。
8. 纯宏观模型与文本增强模型进行了严格比较。
9. 文本更新系数经过样本外评估。
10. 模型能够在数据缺失或文本质量下降时停止自动更新。
11. 每次运行都有数据版本、参数版本和报告记录。
12. 所有最终结论都能区分经济压力、政策关注度和政策行动预测。

**最重要的验收标准不是模型能否输出“通胀关注度 65%”，而是这个数字能否由历史数据重复计算、能否通过样本外检验，以及能否解释它为什么发生变化。**
