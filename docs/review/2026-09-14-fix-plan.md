## 1. IMP-001: POSITION_AGGREGATE 缺失

### 设计依据
- D02 §2 positioning: POSITION_AGGREGATE 与 POSITION 同构（COT 聚合数据）
- 字段: report_date, release_time, contract, participant_type, long_positions, short_positions, spreading, net_position, revision_time
- natural_key = (contract, report_date, participant_type)
- validator: net_position = long_positions - short_positions
- CanonicalType.POSITION_AGGREGATE 已在 enums.py 声明（27 枚举之一）
- REVISION_TYPES 已在 storage/base.py 声明（含 POSITION_AGGREGATE）

### 修改方案
- 在 `positioning.py` 中新增 `POSITION_AGGREGATE` 类，继承 `BaseRecord`
- 字段定义与 `POSITION` 完全相同
- natural_key() 返回 `(self.contract, self.report_date, self.participant_type)`
- net_position validator 与 POSITION 相同逻辑
- 在 `models/__init__.py` 中导出 `POSITION_AGGREGATE`
- 在 `positioning.py` 中导出 `POSITION_AGGREGATE`

### 测试方案
- 在 `tests/unit/test_positioning_types.py` 中新增 `TestPOSITION_AGGREGATE` 类
- 覆盖：合法实例化、net_position 校验、natural_key 契约、所有 ParticipantType

## 2. IMP-002: 错误类层级不完整

### 设计依据
- D01 §3 明确定义了 9 个异常类的完整层级
- 文件位置: `connectors/errors.py`
- 根类: `ChronoForgeError(Exception)`
- 所有异常携带 `context: dict`

### 修改方案

#### 2a. 创建 `src/chronoforge/connectors/errors.py`

```python
class ChronoForgeError(Exception):
    """根异常类（D01 §3）。"""
    def __init__(self, message: str, context: dict | None = None):
        super().__init__(message)
        self.context = context or {}

class TransportError(ChronoForgeError): ...
class RateLimitError(TransportError): ...
class AuthError(ChronoForgeError): ...
class ProviderError(ChronoForgeError): ...
class SchemaError(ChronoForgeError): ...
class QualityError(ChronoForgeError): ...
class ConfigError(ChronoForgeError): ...
```

#### 2b. 更新 `src/chronoforge/exceptions.py`

- 修改现有 `ProviderError` 继承 `ChronoForgeError`
- 修改现有 `StorageError` 继承 `ChronoForgeError`
- 新增 `StorageError` 支持 context 参数

#### 2c. 同步 `connectors/errors.py` 与 `exceptions.py`

D01 §3 声明 `connectors/errors.py` 是错误层级定义位置，但现有实现分散在 `exceptions.py`。决策：
- `exceptions.py` 保留 `StorageError`（storage 层专用，不属 connectors）
- `connectors/errors.py` 定义所有 connector 相关异常
- `StorageError` 同时从 `ChronoForgeError` 继承，保持向后兼容

### 测试方案
- 新增 `tests/unit/test_error_hierarchy.py`
- 测试：层级继承关系、context dict 传递、各异常类可独立实例化

## 3. IMP-003: `get_checkpoint` 返回类型不一致

### 设计依据
- D03 §6 声明: `get_checkpoint(source, ds) -> str | None`
- 实现返回 `dict | None`（`{last_cursor, last_success_time}`）

### 修改方案
- 修改 `get_checkpoint` 返回类型为 `str | None`（仅返回 last_cursor）
- 调用方（如有）改用 `.last_cursor` 访问 → 实际调用方仅内部使用，无外部依赖
- 同时新增 `get_checkpoint_detail` 方法返回完整 dict（保留便利访问）
