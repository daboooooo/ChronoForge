      六、把方案实现成可持续运行的程序
      考虑到你希望使用程序获得可重复的宏观流动性判断，我建议建立一个 Python 项
      目，将数据采集、预测、回测和报告分开。
      数据采集层
      财政部 DTS、拍卖日历、季度融资公告、FRED API
      标准化与校验层
      统一日期、单位、频率；检查缺失值和重复现金流
      预测引擎
      TGA 日度现金流模型 + 美联储资产负债表分解 + 误差校准
      输出层
      1 周、2 周、4 周准备金预测；情景区间；历史误差；风险提示
