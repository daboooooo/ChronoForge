      美元流动性与大饼关联性的分析方
      法
      @qinbafrank
      （Frank）长期把“美元流动性”定义为：
      美元流动性 = 美联储资产负债表 − 隔夜逆回购（ON RRP）− 财政部TGA账户 = 银行
      准备金 + 流通中现金
      他反复强调，银行准备金是其中最核心的变量。过去三年大致区间：低点约2.8万亿美
      元、高点约3.6万亿、中位数约3.2万亿。他个人常用的门槛是：回到3万亿以上算进入
      “充裕”，回到3.2万亿以上才算“充裕且过剩”；跌破约2.8–3万亿则接近紧张。他本人
      在2026年10月2日明确划界：准备金/美元流动性框架主要用来看大饼和加密，不是看
      美股的主框架。
      一、美元流动性（银行准备金）与大饼
      核心观点
       1. 大饼基本面弱，主要靠预期、情绪和资金推动，因此与以银行准备金为核心的美
          元流动性高度相关。 他多次说“大饼没有基本面，靠预期和情绪驱动”，2020年以
          来价格走势与准备金规模相关性很高；与全球M2的关联则弱得多。
       2. 机制：准备金决定银行可贷规模和杠杆空间。华尔街对冲基金等会用银行信用加
          杠杆，准备金被快速消耗时，流动性敏感资产（尤其高杠杆的比特币）承压更明
          显。稳定币发行量和现货ETF净流入常被他当作流动性传导的同步观察指标。
       3. 历史对应（他在2024年9月和2026年3月长文中反复引用）：
             2021年准备金见顶，对应上一轮大饼周期顶部；
             2023年初准备金触底回升，对应大饼后续上行；
             2024年3月中准备金见顶，大致对应大饼当年高点后震荡走弱；
             2025年8月准备金从约3.4万亿见顶，一路下滑到11月约2.85万亿（TGA回补
             耗尽ON RRP + 政府停摆导致TGA堰塞），大饼随之走弱。他强调流动性拐头
             早于市场直观感受的“10·11”事件约一个月。
       4. 实操用法：他几乎每1–2周用最新H.4.1等数据对照大饼。准备金回升 + 稳定币增
          发/ETF净流入时，倾向看反弹空间；准备金回落时，视为压制。形态（如周线底
          背离）需要流动性配合才能走远。
