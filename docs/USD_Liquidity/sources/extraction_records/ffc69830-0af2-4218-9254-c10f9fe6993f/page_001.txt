       美元指数（DXY）—美债收益率
       （UST）—TLT（长债ETF）—
       VIX 的涨跌组合
       下面把 美元指数（DXY）—美债收益率（UST）—TLT（长债ETF）—VIX 的涨跌组
       合，系统化总结成一套**“宏观状态判读表”**。
       这是宏观交易里非常实用的一套“四象限联动框架”，适合判断 Risk-on / Risk-off / 流
       动性变化 / 危机阶段。
       一、先明确每个变量在“说什么”
        指标            本质含义
        美元指数 DXY      全球流动性 & 避险货币需求
        美债收益率（10Y/2Y） 增长预期 + 通胀 + 货币政策
        TLT           长期利率方向（收益率的反向）
        VIX           市场恐慌与不确定性
           记忆法：
           DXY = 钱往哪跑
           收益率 = 经济和通胀怎么看
           TLT = 利率方向确认器
           VIX = 市场是否恐慌


       二、核心市场模式组合（重点）
       ① DXY ↑｜收益率 ↑｜TLT ↓｜VIX ↑
       →   典型：紧缩冲击 / 流动性收缩
