      ✅ 结论：
       EFFR 稍低于 IORB 是结构性结果，不是异常。


      🔄 六、如果 EFFR 高于 IORB，会发生什么？
      假设：
         EFFR = 5.5%
         IORB = 5.4%
      银行会发现：
       “我可以在联邦基金市场借出赚 5.5%，为什么要在美联储只拿 5.4%？”
      于是：
       银行减少在美联储的超额准备金，转而在联邦基金市场上出借，资金供给上升，EFFR 回落至 IORB
       附近。
      ✅ 这就是“天花板体系”的自动稳定机制。
      📈 七、FFR 如何影响其他利率与经济活动
      一条简化传导链：
       FFR ↑
         ↓
       SOFR、T-bill ↑（短端资金成本上升）
         ↓
       银行融资成本 ↑
        ↓
       贷款利率 ↑
        ↓
       消费与投资下降
        ↓
       经济降温 → 通胀下降




      逻辑说明：
      环节                     说明
      FFR → SOFR / T-bill    银行资金变贵 → 回购与国债市场利率上升
      SOFR / T-bill → 银行贷款利率 银行资金成本提高 → 上调贷款利率
      贷款利率 → 消费投资            借贷变贵 → 减少房贷、车贷、企业投资
      最终                     经济活动降温 → 通胀减缓
      📉 反之，美联储降息时：
       资金变便宜 → 短端利率下降 → 贷款更容易 → 消费与投资上升 → 刺激经济。
