      角色             是否能获得 IORB 在市场上角色         行为逻辑
      大型商业银行         ✅          借方 / 贷方        平衡准备金缺口或出借闲钱
      社区银行 / 小银行     ✅          借方             补充准备金以满足监管要求
      FHLB（联邦住房贷款银行） ❌          贷方             出借闲置资金赚取收益
      GSE（房利美、房地美等） ❌           贷方             出借现金但拿不到 IORB
      信用社、储蓄银行       ✅          借方 / 贷方        调节短期资金头寸
      借钱原因：
        清算与支付结算需要；
        准备金分布不均；
        临时资金缺口；
        短期利差套利。
      📌 核心目的：
      不是长期融资，而是隔夜调整准备金余额，保证系统稳定。
      🔍 五、为什么 EFFR 通常低于 IORB？
      表面逻辑（看似合理但错误）：
       IORB 是无风险收益，EFFR 有风险 → 应该 EFFR > IORB

      现实逻辑：
       EFFR < IORB
      原因：
      1️⃣ GSE（不能拿 IORB）在压低市场利率
          它们资金多、缺乏投资渠道；
          只能在联邦基金市场出借资金；
          即便利率比 IORB 低，也比闲置好。
          → 把 EFFR 从上方压下来。

      2️⃣ 银行体系整体流动性过剩
          超额准备金太多，资金供大于求；
          借钱需求弱，利率自然低。
      3️⃣ 信用风险极低
          同业间隔夜无担保借贷，风险溢价接近零。
      4️⃣ 加权平均统计效应
          FHLB 和 GSE 的低价借贷量大 → 直接拉低 EFFR 平均值。
