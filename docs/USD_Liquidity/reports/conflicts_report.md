## 冲突清单（4 项）

### CONF_001 准备金安全下限数值
- **表述A**：美联储官方安全下限 2.7 万亿美元（DOC_FED p11，未附出处）
- **表述B**：过去三年低点约 2.8 万亿美元；跌破约 2.8–3 万亿接近紧张（DOC_LIQ p1，Frank 个人门槛）
- **分析**：两者口径不同——前者为原文声称的『官方』估计（出处待查，OPEN_QUESTION_FED_003），后者为作者观察的历史低点与个人分级阈值。另 DOC_TGA（p4）强调 2.85 万亿只是条件推算值，不等于危险下限。
- **处理**：三条目分别保留为 KP_FED_022 / KP_LIQ_002 / KP_TGA_011，不合并、不替换。

### CONF_002 FOMC 投票成员构成
- **表述A**：『每次会议12位美联储理事将根据经济数据投票』（DOC_FED p1）
- **表述B**：公开制度描述：12 位投票成员 = 7 位理事 + 纽约联储主席 + 4 位轮换地区联储主席（非 12 位理事）
- **分析**：原文表述与公开制度不符，但『12 位投票成员』总数一致，属简化/误述。
- **处理**：保留原文并登记 OPEN_QUESTION_FED_001；知识库规范化表述中注明差异。

### CONF_003 走廊中 EFFR 与 IORB 的关系表述
- **表述A**：正常关系 ON RRP < EFFR < IORB（DOC_FED p2）
- **表述B**：同页又写『EFFR（市场形成，可能高于 IORB）』
- **分析**：两者不矛盾——常态低于、偏离时由套利修复（p4 数值示例），但并列呈现易误读。
- **处理**：合并为『常态低于 + 套利修复机制』（KP_FED_006/007/008），并保留原文两句。

### CONF_004 2023-03 BTC 样本的双重使用
- **表述A**：DOC_FED Pattern 1 将 2023-03-01~08 下跌 >7% 用作『准备金<3万亿→做空』的验证样本
- **表述B**：DOC_LIQ 将 2023 年初『准备金触底回升』用作看多 BTC 的历史对应
- **分析**：同一时间段在不同文档支撑相反方向的操作叙事；可能反映 3 月初准备金仍在红线附近波动、随后回升。
- **处理**：两处均保留并交叉标注（CASE_2023_RESERVE_BOTTOM 的 counter_evidence）；提示用连续周度数据复核触发时点。
